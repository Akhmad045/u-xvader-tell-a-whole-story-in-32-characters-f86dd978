`main.py` writes a single Wi-Fi network name to `/output/entry.txt`:

**Password: Your Anniversary, Dave**

Dave forgot the anniversary, so the Wi-Fi password became the anniversary
itself — the network name is a public scolding, and a whole marriage (the
forgotten date, the punishment, the partner who changed the password) is
implied in the few words a passer-by sees in a phone's network list.
